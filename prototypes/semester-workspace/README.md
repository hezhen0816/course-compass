# 修課羅盤完整介面原型

獨立的 UI／UX 互動原型：本學期、找課、畢業規劃、修課紀錄、選課監控與設定。所有課程、教師、名額均為模擬資料；不讀取正式帳號或呼叫學校、Supabase、監控服務。

## 啟動

在 repository 根目錄執行（沿用 `web/node_modules` 的既有 React、Lucide 與 Vite；尚未安裝時先 `npm ci --prefix web`）：

```sh
npm --prefix prototypes/semester-workspace run dev
```

開啟 http://127.0.0.1:4317/ 。服務只綁定本機。

## 試用

1. 在「加退選」模式點「資料庫系統」查看時段預覽，再「加入預排」；已選學分維持 18，預排學分由 3 變 6。
2. 「加退選」模式會阻擋新增衝堂課；切到「初選志願登記」後，可把「行銷管理」與同時段的「成本會計」一起加入，課表會並排顯示。切回加退選保留草稿並提示重疊。
3. 搜尋課名、課碼或教師，搭配課程類別與「只顯示不衝堂課程」篩選。
4. 桌面點「展開找課」使用寬版列表比較課程、教師、時間與名額；「回到課表」會保留搜尋、類別、篩選與預排。手機維持全螢幕找課。
5. 點預排課程可移除；點「重設示範」回到初始預排。僅修改此原型的瀏覽器儲存。
6. 桌面以週課表開啟；手機以清單開啟，找課為全螢幕面板。可切換週課表。

預排使用獨立 localStorage key `course-compass:semester-prototype:v1`，重整後保留。模式另存於同一 key 加上 `:mode`。初選顯示「志願總量」，不是可同時修讀或已取得學分。模式切換不會刪課。官方選課與待加簽提供操作結果預覽；尚未串接正式選課、志願排序／抽選、畢業規劃或名額監控。

模式是手動情境預覽，不代表目前官方入口已開放。初選登記與抽選後繼續選課的差異見 [學校系統契約](../../docs/data-contracts/ntust-systems.md#5-選課階段以教務處時程表為準)。

## 驗證

```sh
npm --prefix prototypes/semester-workspace run build
node --test prototypes/semester-workspace/*.test.js
```

瀏覽器驗證紀錄見 [design-qa.md](design-qa.md)。本原型不納入正式 Web 的入口、建置或部署。

## 完整找課原型

- 可查課名／課碼／教師；精確課名支援「、」等分隔符一次查多門。
- 進階篩選包含系所、教師、必選修、學分、星期與節次、名額、跨校；條件標籤可個別移除。支援排序與匯出目前結果為 CSV。
- 學期選單提供 115-1 與 114-1 歷史範例。歷史課程不可加入本學期，名額未公告不會視為額滿。
- 詳情包含課綱／評量示範、GPA 狀態、名額、備註、認列意向、追蹤草稿及官方操作結果預覽。
- 待修清單可新增、移除及直接查課；追蹤草稿可移除。待修、追蹤、認列用途會保存至本機；預排仍使用原本獨立 localStorage。
- 頁尾「查詢畫面示範」可切換載入中／連線失敗，再完成模擬載入或重試。查詢本身以本地資料即時篩選，不產生後端請求。

正式替換仍需 API、權限、真實學期、GPA、認列資料及狀態同步整合；此版本完成整套主要頁面與跨頁互動的設計原型。

## 六個入口

| 頁面 | 網址片段 | 可操作內容 |
| --- | --- | --- |
| 本學期 | `#semester` | 週課表／清單、預排、初選重疊志願、課程詳情、筆記與成績試算 |
| 找課 | `#search` | 寬版查詢／手機面板、篩選、歷史、CSV、認列與追蹤草稿 |
| 畢業規劃 | `#graduation` | 主修／雙主修／輔系條件、已通過紀錄、115-2 至 117-2 未來配置、移動學期及查課 |
| 修課紀錄 | `#history` | 學期時間軸、通過／未通過篩選、課名搜尋、筆記與再次查課 |
| 選課監控 | `#monitor` | 共用追蹤清單、暫停／恢復、次數上限、自動加選情境、連線狀態與活動說明 |
| 設定 | `#settings` | 連線正常／過期／離線、模擬同步、通知偏好、目標學分、匯入預覽與去重 |

桌面左側導覽、手機底部導覽皆可切換。網址片段支援直接開啟與瀏覽器歷史導覽。

未來規劃、筆記、追蹤與認列意向、設定及匯入狀態使用獨立 key `course-compass:design-suite:v1`，重新整理後保留。成績試算只在本次詳情保留；不寫入正式成績。

### 建議走一次的完整流程

1. 在設定開啟匯入預覽，套用「科技與倫理」示範；畢業規劃與修課紀錄的完成學分會由 28 更新為 30，再次匯入會略過重複。
2. 在畢業規劃加入未來課程，移到大四 117-2；課程只列為意向，不會計入完成學分。
3. 找課詳情加入追蹤草稿，再到選課監控暫停／恢復；兩邊共用同一清單。
4. 在設定切換登入過期；監控顯示等待連線。切回已連線，可模擬同步但不呼叫外部服務。
5. 查看修課紀錄的未通過離散數學，原始紀錄保留；只有後續通過的 3 學分計入完成。
6. 在課程詳情開啟成績試算，30%×80、30%×90、40%×100 得 91 分；不改動畢業進度。

所有門檻、紀錄與狀態都是設計樣本。未實作正式登入、校務寫入、監控 worker、寄信、實際 GPA 授權或部署。
