# 修課羅盤產品重新定義

日期：2026-06-12
更新：2026-06-13

## 產品定位

修課羅盤是一個台科大修課與選課輔助平台。Web 版負責查詢、選課工作台、畢業進度、歷史修課與未來規劃；iOS 版偏向查閱課表、作業與學分狀態。

本平台可以輔助整理官方選課操作，但不做自動搶課、名額輪詢、自動重試或排程送出。官方選課 POST 僅能在使用者明確確認後單次送出，系統只送一次並顯示官方回應。

## 核心頁面

### 1. 課程查詢

用途：查詢官方開課資料，並把課程加入待選清單。

範圍：
- 查詢課碼、課名、教師、學分、必選修、節次、教室、名額與備註。
- 篩選學期、教師、學分、必選修、節次與名額狀態。
- 加入待選清單或直接排入目前選課工作台。
- 匯出查詢結果。

不負責：
- 長期四年規劃。
- 畢業門檻設定。
- 自動送出官方選課。

### 2. 選課工作台

用途：處理目前最新選課學期的待選清單、志願排序、衝堂檢查與送出前檢查。

範圍：
- 顯示待選清單與本地保存的選課草稿。
- 支援初選志願、加退選、加簽追蹤三種模式。
- 初選模式允許同時段多門課並視為競爭志願。
- 加退選模式把同時段課程視為真衝堂。
- 顯示志願數、已排學分、待排學分與競爭組提醒。
- 送出前必須重新請求官方選課系統資料，並以官方資料與官方回應為準。
- 已支援使用者確認式官方 POST adapter；mutating request 需帶 `confirmed: true`。

不負責：
- 切換大一上、大二上等長期規劃學期。
- 展示完整歷史修課紀錄。
- 編輯畢業門檻數字。

### 3. 畢業進度

用途：對照門檻檢查目前完成度與缺口。

範圍：
- 顯示總學分、共同必修、通識、體育、系所、雙主修、輔修等完成度。
- 標示已完成、進行中、缺口與可能重修項目。
- 可讀取歷史修課、目前選課與未來規劃，但不直接負責排課。

不負責：
- 官方課程查詢。
- 選課志願排序。
- 修改校務同步帳密或同步操作。

### 4. 修課軌跡

用途：集中展示歷史修課、未通過課程、抵免與未來規劃。

範圍：
- 依學期顯示已修、未通過、重修、抵免與預計修課。
- 支援長期修課規劃，例如大二下、大三上預計安排哪些課。
- 讓使用者看出哪些課已經完成、哪些修了沒過、哪些還要修。
- 維護課程詳細資訊，例如教授 Email、上課地點、課程連結與評分項目。

不負責：
- 當期選課送出。
- 官方名額狀態查詢。
- 選課志願序提交。

### 5. 設定

用途：集中管理系統層級設定與敏感操作。

範圍：
- 同步校務資料。
- 設定畢業門檻數字。
- 管理資料匯入與帳號層級設定。

不負責：
- 課程查詢。
- 志願排序。
- 長期課程安排。

## 重要資料概念

- `CourseOffering`：官方開課資料，一個課碼、教師、節次與名額的開課班別。
- `SelectionCandidate`：使用者打算在目前選課學期考慮的課程。
- `SelectionPlan`：目前選課學期的本地草稿，包含志願排序、模式、競爭組與送出前檢查。
- `CourseAttempt`：歷史修課紀錄，包含已通過、未通過、重修與抵免狀態。
- `FuturePlanItem`：長期修課規劃中的預計修課，不等同於目前選課志願。
- `GraduationRequirement`：畢業門檻與分類規則。

目前選課工作台使用 `selectionPlan` 保存本地草稿，避免污染 `semesters` 裡的歷史修課與未來規劃。`selectionPlan.officialSelectionCache` 只作為上次官方清單快照；重新開啟 App 後不可把快取中的 `session_valid` 視為有效 session。後續若要完整支援長期修課規劃，應再設計 `FuturePlanItem` 的資料結構。

## 校務帳號與密碼保存

可做：
- 在設定頁集中管理校務帳號。
- 由學號與官方選課學期推定目前選課對應的大幾學期。
- 同步時讀取官方目前選課清單、歷年成績與課程資訊。

目前做法：
- 不可在前端或本地草稿保存明文密碼。
- 不可用前端可取得的金鑰做假加密後存 Supabase。
- 校務密碼由後端使用伺服器端金鑰加密後保存到 `public.school_credentials`。
- `public.school_credentials` 只開放 `service_role` 存取；Web/iOS 只能透過 backend credential API 查詢保存狀態、保存或刪除。
- 既有 `user_data.content.settings.school_password` 視為舊資料，會在 authenticated credential use 時由後端加密遷移並清除。

## 官方選課整合邊界

可做：
- 課程查詢整合。
- 待選清單與志願排序。
- 衝堂、同課名、學分上限與模式提醒。
- 匯入目前選課清單。
- 使用者確認後單次送出 POST，並顯示官方回應。

不可做：
- 自動搶課。
- 名額輪詢。
- 自動重試。
- 排程送出。
- 使用者未確認就送出官方請求。

## 實作狀態與後續順序

已完成：
- 使用者確認式官方 POST adapter。
- 校務帳密後端加密保存與 session 過期後重新登入。
- Web/iOS 不再新寫入 `user_data.content.settings.school_password`。

後續順序：
1. 穩定目前 UI 資訊架構：課程查詢、選課工作台、畢業進度、修課軌跡、設定。
2. 修正目前選課工作台只處理最新選課學期，不暴露長期學期切換。
3. 把歷史修課與未來規劃移到修課軌跡。
4. 把畢業門檻頁改成真正的進度與缺口檢查。
